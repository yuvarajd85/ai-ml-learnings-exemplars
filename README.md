# AI-ML Learnings Exemplars

This repository contains various AI and ML learning exemplars, workshops, and code samples.

## Important Note About Secrets

**Warning**: This repository previously contained API keys in commit history. All secrets have been removed from the current repository state.

If you encounter issues with secret scanning, please:
1. Create a new branch
2. Push to that branch 
3. Submit a pull request to main branch

## Workshop Content

This repository contains content from various AI/ML workshops including:
- Claude Code Projects and Bedrock AgentCode Exemplars
- Hands-On AI Agent Workshop
- Anthropic API Fundamentals Course
- Other AI/ML learning materials

## Repository Structure

- `claude-projects/` - Claude Code projects
- `notebooks/` - Jupyter notebooks with examples
- `src/` - Source code and workshop materials
- `docs/` - Documentation and cheat sheets

## Getting Started

1. Clone the repository
2. Install dependencies from requirements.txt
3. Set up your API keys in environment variables

## API Keys Setup

For using Anthropic APIs, set the following environment variable:
```
ANTHROPIC_API_KEY=your-api-key-here
```

> Note: Do not commit API keys to this repository. Use .env files or environment variables.
