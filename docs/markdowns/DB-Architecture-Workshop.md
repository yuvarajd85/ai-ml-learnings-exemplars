# Databricks – Guiding Criteria Worksheet (2025)
**Purpose:** Rank business priorities on a 1–10 scale (1 = Low importance, 10 = High importance) across six categories.

---

## 1. Reduction of Costs
- [ ] On-Prem Infrastructure Reduction (Move to Cloud)
- [ ] Cloud Infrastructure Cost Reduction
- [ ] Component Cost Reduction (Migration)
- [ ] Technological Refresh (Upgrades)
- [ ] Performance Improvement (Time Reduction)
- [ ] Efficient Scalability (Up/Down)

## 2. Innovation
- [ ] Use of Predictive Models
- [ ] Use of Machine Learning/Deep Learning (GPU)
- [ ] Use of Generative Intelligence (LLM)
- [ ] Streaming Ingestion (Near Real-Time)
- [ ] Co-Pilot – Coding Assistant
- [ ] Industry Use Case Accelerators

## 3. Integration
- [ ] Integration with Transactional / Cloud
- [ ] Utilization (Integration Cost)
- [ ] Wide Choice of Solutions (Ecosystem)
- [ ] Data Sharing and APIs

## 4. Risk Reduction
- [ ] Reduction of Stops/Failures
- [ ] Improving Security and Compliance
- [ ] Loss Reduction / Breakages / Fraud
- [ ] Lock-In Reduction (Technology)

## 5. Enable the Business
- [ ] Data Driven Culture
- [ ] Democratization of Data
- [ ] Collaboration between Data Teams
- [ ] Integration with Business Solutions
- [ ] GTM – Go to Market (CI/CD Agility)
- [ ] Being Able to Enable New Use Cases (of the business)
- [ ] Competitive Architecture with Other Players
- [ ] Reference Cases (Emerging Themes, e.g. OpenFinance)

## 6. Improvement of Operational Efficiency
- [ ] Architectural Simplification
- [ ] Unification of the Data Lake (Silos)
- [ ] Data Governance
- [ ] Observability and Data Quality
- [ ] Accelerators and Docs (Community)
- [ ] Data Team Productivity
- [ ] Infrastructure as a Service (Terraform)
- [ ] Learning Curve (Professionals)
- [ ] Legacy Compatible Technologies

---

> **Note:** This is a vendor-authored (Databricks) framework — the categories and sub-items are structured in a way that naturally steers toward Databricks' own product strengths (GenAI/LLM, streaming, unified lake, Terraform IaC). If you're using this for genuine internal prioritization rather than as part of a Databricks sales engagement, worth checking whether these buckets actually reflect your org's real constraints or if you're just ranking within a pre-slanted taxonomy.
